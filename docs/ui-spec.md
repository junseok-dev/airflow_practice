# UI 스펙 문서

이 문서는 교육생 역량 분석 대시보드의 디자인 시스템과 페이지별 레이아웃을 정리한 UI 스펙입니다.
Figma 와이어프레임 작업 시 이 문서를 기준으로 사용합니다.

---

| 토큰 | 값 | 사용처 |

## 2. 컴포넌트

### KPI 카드

```
┌─────────────────────────────┐
│ 라벨 (13px, 보조색)           │
│                              │
│ 값 (32px, 강조색)             │
│                              │
│ 헬퍼 (13px, 보조색)           │
└─────────────────────────────┘
```

- 최소 높이 136px, 패딩 20px
- `tone` 옵션: default (네이비), green, red, blue — 값 색상만 변경

### 패널

```
┌─────────────────────────────────┐
│ 패널 헤더 (64px min-height)       │
│  제목 (h2)         서브타이틀     │
├─────────────────────────────────┤
│                                  │
│  콘텐츠 영역                     │
│                                  │
└─────────────────────────────────┘
```

- `panel--wide`: 그리드 전체 너비 spanning

### 배지

```
╭──────────────╮
│  고위험       │
╰──────────────╯
```

- 최소 너비 64px, 패딩 5px 9px
- pill 형태 (border-radius: 999px)

### 세그먼트 컨트롤 (필터)

```
┌────────┬────────┬────────┐
│  전체  │ 고위험 │ 중위험 │
└────────┴────────┴────────┘
```

- 선택된 항목: 네이비 배경 + 흰 텍스트
- 비선택: 투명 배경 + 보조색 텍스트

### 네비게이션 (헤더 내)

```
[ 대시보드 ]  [ 교육생 목록 ]
```

- 활성: 네이비 배경 + 흰 텍스트 (border-radius: 8px)
- 비활성: hover 시 연한 배경

### 테이블

- 헤더: 12px uppercase, 배경 `#f8fafc`
- 행: 14px, 패딩 14px 16px, 구분선 `#eef2f7`
- hover: 배경 `#f1f5fb`
- 교육생 ID 컬럼: 브랜드 블루 링크

### 페이지네이션

```
1 / 163 페이지          [ 이전 ] [ 다음 ]
```

최대 너비 1440px, 좌우 패딩 32px, 세로 스크롤.

### 3-1. 대시보드 (`/`)

├──────────────────────────────────────────────────┤

## 5. Figma 와이어프레임 작업 가이드

### 프레임 크기

| 프레임 | 크기 |
|---|---|
| Desktop (기본) | 1440 × 960 |
| Tablet | 1080 × 960 |
| Mobile | 375 × 812 |

### 컴포넌트 우선순위

Figma에서 만들면 좋은 컴포넌트:

1. **KPI Card** — tone 4가지 variant (default/green/red/blue)
2. **Badge** — risk_level 3가지 variant (high/medium/low)
3. **Panel** — header slot + content slot
4. **Segmented Control** — 버튼 수 가변
5. **App Header** — nav 활성 상태 포함
6. **Table Row** — 기본 / hover 상태

### 색상 스타일

Figma Color Styles로 등록 권장:

- `text/primary` `#172033`
- `text/secondary` `#526071`
- `bg/app` `#f5f7fb`
- `bg/card` `#ffffff`
- `border/default` `#dfe7f2`
- `brand/blue` `#2563eb`
- `risk/high` `#dc2626`
- `risk/medium` `#f59e0b`
- `risk/low` `#0f766e`
