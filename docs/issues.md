### README 저장 충돌

문제:

- README를 에디터에서 열어둔 상태로 외부 도구가 파일을 수정하면서 저장 충돌이 발생했다.
- 에디터에서 `The content of the file is newer` 메시지가 표시되었다.

원인:

- 디스크의 README는 이미 수정되었지만, 에디터 탭에는 이전 버전의 버퍼가 남아 있었다.
- 같은 파일을 에디터와 외부 도구가 동시에 수정한 상태였다.

해결:

- README 탭을 닫아 에디터 버퍼 충돌을 해소했다.
- 이후 디스크 파일 기준으로 README 내용을 다시 확인하고 정리했다.

재발 방지:

- 외부 도구가 파일을 수정한 뒤에는 해당 파일 탭을 닫고 다시 연다.
- 저장 충돌이 발생하면 `Overwrite`, `Revert`, `Compare`의 의미를 확인한 뒤 처리한다.

### README 한글 인코딩 깨짐

문제:

- PowerShell에서 README 또는 Markdown 문서의 한글이 깨져 보였다.

원인:

- Windows 환경에서 UTF-8 BOM 없는 파일을 일부 도구가 다른 인코딩으로 해석했다.

해결:

- README와 생성 문서를 UTF-8 BOM으로 저장했다.

재발 방지:

- 한글 Markdown 문서를 생성할 때 `utf-8-sig` 인코딩을 사용한다.
